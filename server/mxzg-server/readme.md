**mxzg-server** 服务端

基础业务模块：
    
    mxzg-battle 战斗逻辑
    
    mxzg-config 策划数值配置文件
    
    mxzg-protocol 和客户端通讯协议
    
    mxzg-message 和跨服中心服通讯消息
    
    mxzg-template 跨服中心服游戏服公用逻辑

游戏逻辑服：

    mxzg-gameserver 游戏逻辑服
中心服：

    mxzg-center 连接所有游戏逻辑服
跨服：

    mxzg-cross 跨服逻辑玩法
    
工具模块：

    mxzg-tools 游戏工具包，不属于游戏业务，已有工具（客户端模拟工具，压测程序）
