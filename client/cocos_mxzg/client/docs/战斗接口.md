## 战斗接口描述文档

### 用法

战斗播放器的门面为 `src/controller/BattleController.lua` 文件，这个类实现了战斗相关的接口。

#### 准备战场显示对象

在实例化战斗控制器之前，需要先为战斗创建一个 "完备" 的战场显示对象(也就是一个cc.Node对象)，这个对象作为战斗的 "黑板"，战斗的播放就在这个显示对象上进行。

"完备" 的意思是，你必须确保战场对象的 "位置(position)" 和 "大小(contest size)" 是正确的。(因为战斗对象的位置是通过战场大小进行计算的，而位置则是由调用者自己设置)。

#### 战斗控制器的基本使用

你可以在任何地方实例化战斗控制器，每个战斗控制器都会绑定一个上述的战场显示对象，所以这个控制器是可以重用的。下面说明基本的使用方法:

```lua
local BattleController = require('src.controller.BattleController')

-- 创建战场显示对象 btfLayer => battlefieldBattle
local btfLayer = cc.Node:create()

-- 重要 : 一定要设置战场的 位置 和 大小
btfLayer:setPosition(cc.p(0, 100))
btfLayer:setContentSize(cc.size(750, 1234))

-- 使用战场显示对象创建战斗控制器 btController => battleController
local btController = BattleController.new(btfLayer)

-- 获取到战报数据 (数据格式请参考战斗相关的协议: battle.proto => message BattleReport)
local btReport = ...

-- 开始播放战斗。
-- 如果调用了这个函数之后还是一脸懵逼，那么检查一下
btController:play(btReport)
```

#### 战斗事件

```lua
--[[
    添加战斗相关的监听器

    根据你关心的事件来进行监听，比如如果你想要在每个回合开始时更新回合显示UI，
    那么就可以监听回合开始事件
]]

-- 回合开始时的事件监听
btController:addEventListener(BattleController.Event.RoundStart, function(evt)
    -- 回合开始时你要执行的东西......
end)

-- 回合准备阶段结束后的时间监听
-- 回合准备阶段结束是指某些回合性buff等在回合开始时执行的动作执行完之后
btController:addEventListener(BattleController.Event.RoundReadyEnd, function(evt)
    -- 回合准备阶段结束后你要执行的东西......
end)

-- 回合结束时的事件监听
btController:addEventListener(BattleController.Event.RoundEnd, function(evt)
    -- 回合结束时你要执行的东西......
end)

-- 战斗结束时的事件监听
btController:addEventListener(BattleController.Event.BattleEnd, function(evt)
    -- 战斗结束时你要执行的东西......
end)

-- 战斗被强制结束时的事件监听
btController:addEventListener(BattleController.Event.BattleForceEnd, function(evt)
    -- 战斗被强制结束时你要执行的东西......
end)

--[[
    btController:removeEventListener 函数可以删除监听器(虽然不是必要的，只要解除对战斗控制器的引用，即可自动删除)

    这个函数以事件类和函数引用作为参数，前提是这个函数已经被addEventListener
]]
local func = function() ... end
btController:removeEventListener(BattleController.Event.BattleForceEnd, func)
```

#### 战斗事件结构

在发生某个事件时，会将一些信息通过参数的形式附加在回调函数中，以下说明这些结构。

```lua
--[[
    对于回合性的事件，将会有以下结构
    {
        roundNumber: 当前回合的数字
    }

    回合性事件有:
    - BattleController.Event.RoundStart
    - BattleController.Event.RoundReadyEnd
    - BattleController.Event.RoundEnd
]]
```

```lua
--[[
    对于战斗结束事件，将会有以下结构
    {
        isWin: 战斗是否胜利
    }

    战斗结束事件有:
    - BattleController.Event.BattleEnd
    - BattleController.Event.BattleForceEnd
]]
```

#### 检查战斗是否正在播放

```lua
-- 可以检查这个战斗控制器是否正在播放战斗
if btController:isPlaying() then
    -- 执行一些东西......
end
```

#### 强制停止战斗

```lua
-- 调用这个函数将会强制停止正在进行的战斗
-- 不过，如果某个英雄正在执行动作，那么会等待这个英雄执行完动作才会发送战斗停止事件
-- 那么如果你想在这之前执行操作，那么可以调用完这个函数之后马上执行你想要的操作，然后
-- 收到事件之后再执行其他的操作(事件发送的时刻可以保证战斗对象已经清理完毕)
btController:forceStop()
```

#### 改变战斗速度

改变战斗速度有两种方式，一种是自行去获取全局的战斗调度器，另一种是直接在战斗控制器对象中调用修改战斗速度的函数。

但是，不管怎么修改，这个战斗速度都是全局有效的(战斗控制器也是在全局的战斗调度器中修改速度的)

```lua
-- 自己获取战斗调度器，并调用setTimeScale函数修改战斗播放速度倍数
GlobalBattleHelper.getScheduler():setTimeScale(2.0)

-- 使用战斗控制器对象修改战斗播放速度倍数
btController:setPlaySpeedScale(2.0)
```
